# ملخص بالعربي — Omar Ayman | مهندس أتمتة وذكاء اصطناعي

طالب علوم حاسب (جامعة كفر الشيخ) متخصص في أتمتة الأعمال باستخدام **n8n** وربطها بالـ APIs وأنظمة الذكاء الاصطناعي. الريبو ده فيه 10 مشاريع موثقة، وكل مشروع مكتوب فيه بصراحة: هل هو مشروع عميل، أو مشروع تدريب، أو عمل فريق، أو نموذج تجريبي، وإيه اللي اتختبر فعلا وإيه اللي لسه.

## أبرز المشاريع

| المشروع | المشكلة | الفكرة التقنية | الحالة |
|---|---|---|---|
| **Students Booking V1** | تسجيل الطلاب يدويا بين الواتساب والتليفون | كشف التكرار، فحص سعة المجموعات، قائمة انتظار، إشعارات تليجرام | استُخدم مع مركز تعليمي حقيقي (الأرقام من المالك وغير مقاسة في الريبو) |
| **Students Booking V2** | أخطاء الكتابة الجزئية والتكرار | `event_id` + سجل Ledger + `LockService` في Apps Script | نسخة تطوير وعرض (ليست ما سُلّم للعميل)، اختبار تجريبي بـ 50 تسجيل وهمي |
| **Certificate Automation** | إصدار شهادات PDF وإرسالها دون تكرار | حالات `pending → sending → issued / delivery_unknown` | نموذج تجريبي، 32 فحص محلي ناجح |
| **Invoice Processing** | أخطاء استخراج الـ AI للفواتير | استخراج Gemini + تحقق بـ JavaScript + موافقة بشرية | مشروع تدريب (DEPI)، تجربة بفاتورة تجريبية |
| **Order Tracking** | إشعار العملاء بتتبع الطلب بأمان | التحقق من توقيع HMAC على الـ raw body | مشروع تدريب، اختبار بـ Postman |
| **HR Recruitment** | فرز المتقدمين | تصنيف Gemini + قرار بشري عبر أزرار تليجرام | نموذج تجريبي، قرار المسؤول فقط |
| **Supabase RAG** | إجابات العملاء من ملفات الشركة | Drive → تقطيع → Embeddings → Supabase → تليجرام | نسخة مصححة، لم تُشغّل end-to-end |
| **Alexa Assistant** | مساعد شخصي (Gmail, Calendar, Airtable) | وكيل بأدوات + قائمة مستخدمين مسموح لهم | نموذج تجريبي |
| **Multi-Agent** | بحث تسويقي سريع | وكيل مشرف + وكيل بحث + وكيل تحليل | نموذج تجريبي |
| **HSE Weekly Analysis** | تقرير أسبوعي للحوادث | جدولة + وكيل AI + تقرير HTML | **مشروع فريق** |

## مبادئ الشغل

- **الـ AI يقترح والكود يتحقق:** مخرجات النموذج بتتراجع بقواعد حتمية قبل أي إجراء.
- **القرار الحساس بيد إنسان:** الموافقة على الفواتير وقبول المرشحين.
- **حالات واضحة:** كل عملية لها status قابلة للمراجعة بدل افتراض النجاح.
- **صدق في التوثيق:** قسم "Limitations" في كل مشروع، وجدول يفرق بين ما شوهد وما هو معلق.

## الاختبارات

سكريبتات Node تعمل بدون أي مكتبات: `scripts/validate-repo.js` (JSON، الربط، الأسرار، اللينكات) و3 سكريبتات لاختبار منطق المشاريع. هي اختبارات منطق محلية، وليست تشغيلا على n8n ولا اختبار تزامن حقيقي.
